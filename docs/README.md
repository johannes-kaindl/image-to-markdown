# Image to Markdown — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](manual/tutorial.md) — from a local vision server to your first transcript note.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](manual/tutorial.md)** | Learning-oriented. Start LM Studio, point the plugin at it, transcribe one image. |
| **[How-to guides](manual/how-to.md)** | Task-oriented. PDFs, single images from the editor menu, HEIC, several endpoints, prompt presets. |
| **[Reference](manual/reference.md)** | Information-oriented. Every setting, command, format and frontmatter key. |
| **[Explanation](manual/explanation.md)** | Understanding-oriented. Why it is local, non-destructive and idempotent, and why PDFs render in the app. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "Vision LLM offline", "Empty transcript", "Format .heic not supported". |

The [README](https://github.com/johannes-kaindl/image-to-markdown/blob/main/README.md) covers what the plugin does and how to install it. The [manual home](manual/index.md) is the older entry point to the four manual pages above.
